# DEEN AI — Store Listing Draft

## App name
DEEN AI

## Short description
Learn, ask and explore Islamic knowledge in one app.

## Full description
DEEN AI is an educational Islamic learning app designed to bring learning tools together in a simple mobile experience.

Planned features include:
- AI-powered Islamic Q&A
- Quran learning
- Hadith learning with source references
- Islamic knowledge quizzes
- Simple, distraction-free interface

AI answers are educational and should be checked against reliable sources. Questions involving specific religious rulings should be verified with a qualified scholar.
