# DEEN AI

DEEN AI is a Flutter-based Islamic learning and AI assistant app.

## Current structure

- Flutter app configuration
- Material 3 UI
- Home screen
- Deen AI chat screen
- Quran, Hadith and Daily Quiz feature placeholders

## Next build steps

1. Connect the AI response service securely.
2. Add Quran and Hadith data with source references.
3. Add Islamic quiz content.
4. Add settings, privacy information and error handling.
5. Test Android release build and prepare Play Store assets.

Important: AI-generated religious answers should be checked against reliable primary sources and, for rulings, a qualified scholar.

Build workflow note: Android CI removes Flutter's generated sample widget test before analysis.
